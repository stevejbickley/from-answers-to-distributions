# Preregistered analysis plan

## Primary question

Do probability distributions exposed by two different machine interfaces reproduce cross-national human survey response distributions, and do conclusions differ between next-token and decision-native probabilities?

## Probability semantics

- Human: between-person response frequency within a country/territory.
- OpenAI: conditional next-token probability over controlled single-token labels, renormalized over permitted labels.
- Jev: direct probability over declared choices returned by a typed decision interface.

A numerical match is empirical; semantic equivalence is not assumed.

## Primary sample

All countries/territories retained by the source cultural-map replication and with valid human distributions for the relevant item. Primary distributional items: A008, A165, E018, E025, F063, F118, F120, G006, Y002. Y003 is analyzed separately at the constituent-marginal level and included in expected-score cultural-map projections.

## Primary estimator

Within each country-year and item, estimate survey-weighted response proportions using S017. Average the country-year probability vectors equally within country, mirroring the source study's treatment of country-year map scores. Renormalize to sum to one.

For each model provider, average its ten semantically equivalent respondent-descriptor variants at the probability-vector level.

## Metrics

Primary: Jensen-Shannon divergence (base 2; bounded 0–1).
Secondary: total variation distance; normalized 1-Wasserstein distance for ordered scales; absolute expected-score error; normalized entropy error; effective-number-of-categories error.

## Main contrast

For every country × item where both systems are observed, calculate `error_OpenAI − error_Jev`. Positive values indicate lower error for Jev. Report the mean paired difference with a 95% crossed bootstrap interval generated by independently resampling countries and items with replacement. Report paired Wilcoxon signed-rank tests only as robustness statistics, not as the sole inferential result.

## Prompt robustness

For each country × item × provider, compare each of the ten wording variants to that provider's across-variant mean distribution using JSD. Report the distribution of within-provider prompt sensitivity.

## OpenAI completeness diagnostics

The Responses API exposes at most the configured top 20 alternatives per output position. The primary response sets have at most 12 labels. For every call report:

- number of allowed labels absent from returned top-logprobs,
- pre-renormalization probability mass assigned to observed allowed labels (`allowed_mass`), and
- generated token.

Primary analysis requires no missing allowed labels. If any occur, report their frequency and repeat the main analysis under (i) complete-case restriction and (ii) a conservative sensitivity bound. Do not silently set unseen labels to exact zero and present the result as a complete distribution.

## Label/order robustness

Primary prompts preserve semantic option order but rotate single-token labels across the ten prompt variants. A supplementary randomized option-order experiment repeats a stratified subset under balanced permutations to quantify list/order effects. The same substantive answer set is used throughout.

## Y002

Models choose among 12 possible ordered pairs of distinct goals. Pair probabilities are aggregated into WVS Y002 classes: materialist (goals 1 and 3), post-materialist (2 and 4), or mixed (one from each group). Human comparison therefore occurs on the 3-category Y002 distribution.

## Y003

The original multi-select response space contains 1,024 subsets of up to five of 11 qualities and therefore cannot be exhaustively recovered from OpenAI top-20 token alternatives or Jev's 255-choice ceiling. The primary full-distribution comparison excludes Y003. Instead, estimate the four marginal selection probabilities used by the WVS autonomy index: Independence, Determination/perseverance, Religious faith, and Obedience. Compare each marginal to the corresponding human frequency. The expected index is exactly `p(Independence)+p(Determination)-p(Religious faith)-p(Obedience)`; this expectation does not require independence among selections.

## Cultural-map replication

Fit the 10-variable weighted PCA on human microdata using pairwise weighted correlations, two components, varimax rotation, and regression-style factor scoring. Orient factors so Y003 loads positively on the survival/self-expression component and F063 negatively on the traditional/secular component. Project model expected item scores into the same fitted space and apply the rescaling constants stated in the source paper. Compare country-prompted model coordinates with human country coordinates using Euclidean distance.

Because software implementations of factor scoring may differ from the original SPSS pipeline, validate reproduced human coordinates against the published/archived coordinates before interpreting model differences. If discrepancies are material, use the archived loading/scoring coefficients from the source replication when available and report the validation.
